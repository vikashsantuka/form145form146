# Form145Form146.com (NRI Foundation)

Static site for Form 145 / Form 146 (formerly 15CA / 15CB), generated by `build.py`.

- Edit copy in `content.py`; prices, claims, contact, social and analytics settings at the top of `build.py`.
- Build: `python3 build.py` → `dist/` (no dependencies beyond Python 3.9+).
- Cloudflare Pages: build command `python3 build.py`, output directory `dist`. Every push to `main` redeploys.
- Lead forms post to Supabase (NRI360 project, table `nrif_leads`); team CRM at `/crm/`. SQL in `supabase/`.
- Bank form PDFs: replace `src/assets/forms/<bank-slug>.pdf`.
- Social images: `node tools/og.js dist src/assets/og` after changing page headings (needs Playwright).
- Go-live and redirect steps: `GO-LIVE.md`.
